# RemoteShade 当前架构

应用使用 Swift 与 AppKit 提供菜单栏入口，通过 SMAppService 管理当前用户登录后的自启动。

## 自动控制

System/SessionProbe 从系统电源断言检测 Apple 屏幕共享会话，核对系统进程和 Remote user is connected 断言。每 0.5 秒采样。锁屏状态通过当前会话字典和系统通知获得。

远控连接后由 Display/BrightnessController 串行保存每台显示器原亮度和 Gamma，并执行 DDC 0 加 Gamma 0。每 5 秒复查显示器。启用断开自动锁屏时，首次确认断开即请求锁屏并恢复显示。其余情况下断开稳定 2 秒后恢复。恢复值在本次运行中保留，以便在锁屏或唤醒后复查。

无远控且锁屏时，由 Policy/DisplayPolicy 按用户选择的 1、3、5、10 秒或自定义延时请求系统熄屏。解锁取消计时。每次锁屏仅派发一次自动熄屏请求。屏幕已休眠或随后被键鼠唤醒时，将此锁屏周期标记为已处理，防止用户输入密码时再次被熄屏。下一次解锁再锁屏时重新计时。计时从观察到锁屏开始，亮度恢复与倒计时并行；恢复完成后才允许派发熄屏命令。

## 恢复与存储

应用保持内部标识 cn.leaflab.display-guard，延续改名前的偏好设置。brightnessRecovery 和 gammaRecovery 按显示器 UUID 保存原状态，在修改显示器前同步写入。关闭黑屏开关、断开远控、退出或下次启动时恢复。不可达的显示器保留恢复记录。硬件亮度若已被用户改成非零值，恢复时保留用户新值。

## 模块

App 管理菜单与应用生命周期。Display 管理 DDC 与 Gamma，System 采集系统状态，Policy 计算延时和重试。Helpers/DDCBrightness.m 为应用提供限定的 JSON 列表与亮度读写命令。Vendor 仅保留底层 DDC 通信依赖。

## 验证边界

当前核心远控黑屏与断开恢复已由用户在 M4 Mac mini、HDMI 显示器、macOS 26.7 上验证。其他显示器及远控模式仍需适配。锁屏状态键、即时锁屏接口和 IOAV DDC 接口存在非公开契约，需随系统升级复验。Gamma 可能受到其他调光软件影响。

DDC 硬件关机方向及软件开机失败原因保留在 experiments.md。应用当前使用组合调光方案。

## 0.5.4 系统自动休眠修正

旧版“允许自动休眠”仅持有或释放电源断言，不能开启系统本身已关闭的自动休眠，此实现已删除。新 SystemSleepController 通过 `pmset -g custom` 读取电源模式；以管理员授权执行白名单 pmset sleep 命令并读回验证。关闭设置为 0，开启恢复按电源模式保存的有效时长，缺失时为 10 分钟。使用后台串行队列避免认证等待阻塞显示恢复；取消或失败后重新读取真实状态。每 5 秒和菜单展开时读取，退出不回滚，启动不自动写系统设置。
